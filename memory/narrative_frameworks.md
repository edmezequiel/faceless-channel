# Narrative Frameworks (Cinematic RAG)

Este documento serve como a base de dados em memória para o **Script Architect Agent** definir a estrutura temporal dos vídeos.

## 1. Estrutura de Retenção Extrema (Estilo MrBeast/Magnates)
- **00:00 - 00:05 | O Gancho (The Hook)**: Deve quebrar o padrão imediatamente. Fazer uma afirmação contraintuitiva ou uma promessa visual.
- **00:05 - 00:30 | Setup & Curiosity Gap**: O que o espectador vai perder se sair agora? Abro o "Open Loop" principal.
- **00:30 - 03:00 | Escalação**: Apresento fatos rápidos em ciclos de 45 segundos. A cada 45s, a narrativa deve mudar de direção sutilmente.
- **03:00 - 03:30 | Midpoint Twist**: A reviravolta no meio da história. Onde tudo que parecia verdade é questionado.
- **08:00 | Clímax (Resolução do Open Loop)**: A resposta para a pergunta do início.

## 2. Padrões de Interrupção (Pattern Interrupts)
- **Mudança de Ângulo / B-Roll**: A cada 3 a 5 segundos (Aplicado pelo Visual Storyboarder).
- **Mudança de Tom de Voz**: A cada 45 segundos o roteirista deve inserir uma `[PAUSA_DRAMATICA]` ou `[TOM_MISTERIOSO]`.

## 3. Jornada do Herói Adaptada para Documentários Faceless
1. O Status Quo (O senso comum que está errado).
2. O Incidente Incitante (A prova de que a história oficial é uma mentira).
3. A Exploração (Apresentação dos dados do Researcher Agent).
4. O Retorno (Conclusão e lição moral).
